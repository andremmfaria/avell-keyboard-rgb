# Hardware tests

This directory holds interactive scripts that are run by hand on a laptop with the real ITE 8291 keyboard and are never run by CI or collected by pytest, because their file names do not start with test_ and contain a hyphen. `hw-test-installed.py` tests the installed package (the avell-rgbd daemon and the avell-rgb CLI) rather than raw frames: it checks the daemon and device, then walks through suspend and resume, wave directions, the direction byte on other effects, the rainbow palette question, brightness and colour cast, asking what you see at each step and writing commands and answers to a log in `~/Downloads`. Run it as the normal user with `python3 hw-test-installed.py`, or add `--dry-run` to only print the commands. It needs only the Python standard library, never saves anything to the keyboard firmware, and restores white lighting when it finishes.
